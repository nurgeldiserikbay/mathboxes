# Исходники бренда

Два файла, из которых `make-brand.mjs` выводит всё остальное: значки для
сборки, значок витрины, баннер и заплатку запуска.

| файл | что это | откуда |
| --- | --- | --- |
| `icon-source.png` | квадратный рисунок значка | нарисован в ChatGPT 13.09.2026 |
| `banner-source.png` | баннер витрины | там же |

## Это восстановленные копии, а не оригиналы

Оригиналы были 1254×1254 и 1795×876. Они пропали из этой папки 14.09.2026, и
причину я установить не смог: в корзине их нет, на дисках тоже, скрипты сборки
ничего не удаляют. Лежавшие здесь файлы в git не попадали, поэтому и восстановить
их из истории нельзя.

Вместо них здесь лежат производные, уцелевшие в `resources/` и `upload/`:
значок — из `resources/icon-only.png`, баннер — из
`_docs/store/upload/feature-graphic-1024x500.png`.

**Для сегодняшней выкладки это ничего не меняет.** Ни один выходной файл не
требует больше 1024 пикселей: адаптивный значок собирается из 1024, витринный из
512, заплатка из 760, а баннер 1024×500 — это и есть конечный размер, его
исходник был обрезан ровно до него.

**Но запаса на будущее теперь нет.** Если понадобится значок крупнее — скажем,
под iOS или под печать, — увеличивать будет неоткуда. Положите сюда обратно
исходные файлы из ChatGPT под теми же именами, и этот раздел можно будет
удалить.
